complete-record manifest pattern. It binds the full same-page image transform,
review event,scalar field/span digests,node geometry,connector routes and printed
branch-label fields. START/END/Yes/No are ordinary located scalar fields only when
visible. Unlabelled edges use null labels;an outgoing cutoff uses a separately
recorded unresolved connector,never a fabricated endpoint.

Keep full provenance metadata outside embedding text. Serialize each local node's
small outgoing-edge projection beside its actual scalar field,with a fixed
complete-versus-limited-source statement. Enforce the complete manifest/field set
across every required companion before admitting any context. Source completeness
requires a visible terminal,no unresolved connector and no source limits;visible
topology alone cannot repair a clipped predicate. The older complete-arrow codec
retains its stricter contract. Plain service groups serialize byte-identically.

Builder checks the annotation event's source/hash binding;runtime revalidates saved
manifest geometry,fields,limits,whole closure and exact serialized projection.
Trusted reviewed geometry remains caller-supplied evidence,not visual recognition
or school approval. Keep source-limit messages,scope,read-only/privacy and release
