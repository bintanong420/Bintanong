# Reviewed readings to separate pending chunks

13 October 2026. Implement the bounded
[adapter plan](../../plans/2026-10-13-reviewed-policy-pending-chunks-plan.md)
through `document_ingest/reviewed_policy_chunks.py`. The original preparation,
source registers and canonical candidate bundles remain intact.

The adapter revalidates source/event bytes, reconstructs the preparation's core
and refuses altered selection, event metadata, counts or active flags. It reparses
both source registers and field spans. Only explicit undergraduate applicability,
confirmed scalar fields, exact source/version/pages/text and complete valid source
geometry can produce a pending chunk. Field-to-span declarations remain trusted
caller mappings; hash and structural validity do not prove institutional approval.

Named fields, joint roles and literal blank values stay together in one structured
chunk display. Source_text retains exact ordered span text. Field associations
point to span indexes; review-event hashes are neutral artifact references rather
than privileged status labels. Register binding keeps verification/content-review
pending and audience scope reflects only explicit undergraduate selection.

Gap-bearing readings are withheld because the current retrieval context code does
not propagate institutional source defects. Missing applicability or source spans,
null/structured values needing a defined mapping, partial review, duplicate spans
and oversized rows are also withheld. The entire original preparation and gap
details remain in a sidecar; absent fees/sanctions/process endings acquire no
default interpretation. Structured review evidence is never flattened into guessed
scalar facts. The actual saved bundle retains 66 unknown applicability declarations.

Required reading dependencies translate to required_neighbor_chunk_ids only when
all required context survives, from the same source version. Withholding propagates
through the graph; cycles stay atomic. Final chunk IDs incorporate the complete
transitive dependency content using base digests, so a changed exception invalidates
the parent identity without recursive hashing. Token estimates bound both original
span text and structured display; exact tokenizer counts remain a later gate.

This adapter produces a separate inactive candidate result, not a replacement
complete root bundle. Runtime context currently reconstructs text from spans;
structured field displays therefore require a later explicit context integration
and overlap/atomic-association regressions before approved retrieval. No runtime,
storage, embedding, publication or executable-rule change is claimed here.
